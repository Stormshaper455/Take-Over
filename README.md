# Take-Over

Our cybersecurity awareness game for a hackathon, built using HTML, CSS, and JavaScript.

## Getting started

Open `index.html` in a browser. No install is required. The starter displays a blank white laptop screen on a workstation background, ready for the game UI. The background image is loaded from an external site.

- `index.html` — game screen and laptop layout
- `style.css` — workstation background and laptop appearance
- `script.js` — future game logic
